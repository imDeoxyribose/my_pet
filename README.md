# 桌宠项目

一个基于Qt框架开发的桌面宠物应用程序，具有以下功能：

## 功能特性

- 🐾 **宠物动画**：支持空闲、睡眠等状态的动画效果
- 👀 **眼睛跟随**：宠物的眼睛会跟随鼠标移动
- 💤 **睡眠模式**：按下空格键或右键菜单可切换睡眠状态
- 😴 **Z动画**：睡眠时会出现浮动的Z动画效果
- 🖱️ **拖动功能**：可拖动宠物到屏幕任意位置
- 📋 **右键菜单**：包含退出和睡眠/唤醒选项
- 🔄 **平滑过渡**：状态切换时具有平滑的动画过渡效果

## 技术栈

- **开发框架**：Qt 5.15+
- **编程语言**：C++
- **构建系统**：CMake

## 项目结构

```
my_pet/
├── main.cpp              # 主入口文件
├── petWindow.cpp/h       # 窗口管理和渲染
├── petController.cpp/h   # 动画控制和状态管理
├── res.qrc               # Qt资源文件
├── CMakeLists.txt        # 构建配置
└── resources/            # 资源文件
    └── images/           # 图片资源
        ├── face/         # 脸部动画帧
        ├── eyes/         # 眼睛动画帧
        └── Z/            # Z动画资源
```

## 快速开始

### 环境要求

- Qt 5.15 或更高版本
- CMake 3.16 或更高版本
- C++11 兼容编译器

### 构建步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd my_pet
   ```

2. **创建构建目录**
   ```bash
   mkdir build
   cd build
   ```

3. **配置项目**
   ```bash
   cmake ..
   ```

4. **构建项目**
   ```bash
   cmake --build .
   ```
   

## 使用说明

- **拖动宠物**：鼠标左键点击并拖动
- **睡眠/唤醒**：按下空格键或右键菜单选择
- **退出程序**：右键菜单选择"退出"或使用 Alt+F4

## 动画效果

- **空闲状态**：宠物会有轻微的缩放动画
- **睡眠状态**：宠物会逐渐进入睡眠状态，眼睛闭合，出现Z动画
- **Z动画**：睡眠时Z图片会从无到有出现，并具有浮动效果
